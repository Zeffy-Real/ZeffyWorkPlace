## 2. 各主题实现与审查闭环

### A3 压缩 + 加密（核心锚点）
**实现**：写路径「明文→压缩→流式加密→落盘」。`compress.py` 三级熵决策 + gzip 流式压缩/解压 + 压缩指纹；`crypto.py` **加密头版本化 HEAD_VER_EXT=2**——3B 压缩标识（flag/algo/level）并入头 meta 纳入 32B HMAC，全量/流式/Range/重裹动态头长，存量 HEAD_VER 零兼容破坏；`upload` 加密前算明文哈希 + 压缩注入；`artifacts` 读路径透明解压 + 压缩文件 Range 降级全量。

| 🔴 审查项 | 闭环方式 |
|---|---|
| 去重/压缩参数错配→数据损坏 | 压缩标识入密文头 HMAC，篡改即解密失败；不同压缩参数不共享物理块 |
| 压缩标记无完整性→乱码 | extra 并入 HMAC 认证（专项篡改用例） |
| 熵检查流缺陷/流不可重读 | 首块采样单向决策（不回退流）+ 扩展名/阈值三级 |
| 内存峰值不可控/明文残留 | 统一流式单块缓冲，峰值≤2×块槽断言 |

### C1 深冷批量解冻
**实现**：三段式「预估→确认→异步限流执行→通知」。`cold_thawing.py` 扫描冷对象返回费用/时长并签发 **HMAC 签名 token**（范围+结果+操作人）；confirm 校验入队；异步 worker 并发/RPS 限流 + 指数退避重试 + 游标推进；job 快照写 AuditLog + 启动 `recover` 从审计重建续跑；进度/取消接口 admin-only。

| 🔴 审查项 | 闭环方式 |
|---|---|
| 预估 token 无内容校验→成本失控 | HMAC 签名（范围+结果+操作人）+ 绑操作人 + 一次性 |
| S3 配额多维限制缺失 | 并发/RPS/字节三维限流 + 超限指数退避重试 |
| 任务无持久化/无重试 | AuditLog 快照 + 启动 recover 游标续跑 + 指数退避 |

### C2 版本回滚
**实现**：纯元数据预览（不移动/复制）+ 事务化内容落位回滚。`version_rollback.py` 预览返回状态快照 + 一次性 token（绑操作人）；回滚把目标历史版本内容**原子写回主 key**、旧当前内容归档为新版本号（不覆盖版本链）、Artifact 元表 size/sha256 + 配额 `bump_quota` 同一 DB 事务，失败还原主 key 全成/全败，tier 继承不触发分层；审计全字段。

| 🔴 审查项 | 闭环方式 |
|---|---|
| 物理操作非原子→丢文件 | 单 DB 事务 + 原子写主 key + 失败还原；生成新版本号不覆盖 |
| 配额/分层时序漏洞 | size/sha+配额同事务；tier 继承不立即分层 |
| 权限与审计边界不足 | `VERSION_ROLLBACK_ADMIN_ONLY`(默认 true) + token 绑人/一次性 + 审计全字段 |
