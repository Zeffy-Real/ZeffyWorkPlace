## 2. D1 Agent 生态 · 插件市场

**实现**：`app/plugins/`（market 独立 JSON 存储于 `PLUGINS_STORE_DIR`，不触碰主线 DB/存储）。

| 🔴 审查项 | 闭环方式 |
|---|---|
| 边界无技术强制 | 受限作用域 exec（仅注入白名单对象 + 受限内置禁 `__import__/open/eval/exec/compile`）+ 静态扫描门禁 + 上架四门禁 |
| 权限粒度过粗 | 三级 RO/RW/ADMIN + 默认 NONE + 最小权限（逐能力声明），第三方禁 ADMIN |
| 沙箱强度不足 | 明确**能力沙箱**（非进程沙箱）：作用域隔离+调用校验+异常熔断；演进路径留进程沙箱 |
| 上架安全门禁缺失 | 四门禁：完整性/签名(官方摘要)/静态安全扫描/权限审核；黑名单即时失能+解黑恢复 |
| 资源隔离无细则 | market 独立 JSON；总闸 `PLUGINS_ENABLED ∧ ARTIFACT_META_ENABLED`；执行集成 `sync_enabled_plugins` 熔断不影响主线 |

管理 API `/plugins`：浏览/安装/启停（任意登录用户）；上架/下架/拉黑（仅 `ENABLE_ADMIN`+admin，否则 404）。

## 3. D2 多 Agent 协作深化

**实现**：`app/collab/`（并行派发 + 脱敏上下文 + 评审收敛门闸 + 独立协作审计）+ runner/templates（`parallel` 模板）。

| 🔴 审查项 | 闭环方式 |
|---|---|
| 层间边界无隔离 | collab 仅协作逻辑、禁直调主线内部；数据经公开协议/产物 API |
| 任务真相源保护 | **仅子步骤级并行，不产生独立 TaskNode**；子步状态收敛回主 TaskNode，唯一真相源统一写回 |
| 并行回滚原子性 | `run_parallel` 任一子步失败 → 整批 `ok=False` + 取消在途；调用方把主节点置 failed，不留半成功态 |
| 上下文安全 | 敏感字段负面清单递归脱敏；`SharedContext` 绑定 task_id+owner，跨任务/跨 owner 返回空 |
| 评审环无收敛 | `ReviewGate`：迭代上限 + 总超时 + 死循环检测（同意见归一化重复≥2）+ 人工裁决入口 |
| 资源隔离/错峰 | 独立 `AGENT_COLLAB_WORKER_POOL` 并发槽；协作审计独立 JSON（`AGENT_COLLAB_STORE_DIR`），不写主线 DB |

`parallel` 模板节点：需求分析(supervisor)→并行执行(collab)→评审(reviewer)→验收(human/HITL)。

## 4. 兼容锚点

两组总开关默认关闭，关闭时行为与既有一致（零漂移）：
- D1：`PLUGINS_ENABLED=false` → 插件完全不加载；`/plugins` 一律 404；
- D2：`AGENT_COLLAB_ENABLED=false` → 并行/脱敏/评审门闸不生效，runner 走既有顺序流转。

全局总闸 `ARTIFACT_META_ENABLED=false` 亦短路二者。
