## 2. P5-5 上传断点续传（修订后）

**块模型**：`UPLOAD_CHUNK=8MB`，末块可小。暂存区 `artifacts/_upload/{upload_id}/`（`.meta` + `{offset}.part`）。

**upload_id = 服务端 `uuid.uuid4().hex`**（客户端不可控）。

**互斥 + 断点**：同一 `(task_id, rel)` 至多一个活跃上传。init 扫描 `.meta` 匹配 `(task,rel)`：
- 存在**同签名（size+md5）**活跃 → 返回其 `upload_id` + `next_offset`（断点续传，`next_offset=最大连续完整偏移`）；
- 存在**异签名**活跃 → 作废旧上传（清临时文件）→ 新建 upload_id；
- 均无 → 新建。

**四接口 + 二辅助**：
1. `POST /upload/init {task_id,rel,size,md5?}` → `{upload_id, chunk_size, next_offset, done}`（🔴4 互斥 / 🔴3 连续偏移）
2. `PUT /upload/{upload_id}/chunk?offset=N` body=原始二进制
   - 校验：`offset` 非负整数且对齐；**只接受 `offset == next_offset`（连续前进）或已存在（幂等重试）**，非法/空洞即 400（🔴3 连续）；
   - 块级原子+幂等（🔴1）：`backend.put` 原子写；已存在且 SHA256 一致→跳过；不一致→overwrite 修复；
   - 更新 `.meta.last_active`；
   - 响应 `{received=最大连续偏移}`
3. `POST /upload/{upload_id}/commit`（🔴2 原子 / 🔴5 完整性）
   - 预校验磁盘剩余空间（Local），不足即 400（🔴2 防磁盘打爆）；
   - 校验全部块连续完整；整体 SHA256 **始终计算**（无论用户是否给 md5）并作为响应返回；给出 md5 时比对；
   - 流式 `vm.put(key, _concat(), mode='overwrite')` 原子落位（走版本链）→ 成功清暂存 → 审计；
   - 幂等：落位成功后暂存已清，重复 commit 返回 404（不重复执行）。
4. `DELETE /upload/{upload_id}`（🔴⭐ 取消）：主动清暂存 + 审计。
5. `GET /upload/{upload_id}`（⭐ 状态）：返回 `{size, received, next_offset, done, created_at, last_active}`。
6. 守护清理（🔴6 不误杀）：仅清 `last_active` 距今超 `UPLOAD_TTL` 的上传；清理写审计。

**配置**：`UPLOAD_ENABLED`（默认关）、`UPLOAD_CHUNK`、`UPLOAD_MAX_SIZE=2GB`、`UPLOAD_TTL=24h`、`UPLOAD_ALLOW_EXT`（空=不限制，⭐）。

## 3. P5-6 流式直写磁盘（修订后）

**目标**：超大文件不落内存 Blob 直接写盘；仅 Chromium。

**修订闭环**：
- 🔴4 降级体验：仅能力可用时显示「另存为」入口；不可用隐藏该入口（或点击提示后走普通下载），避免预期错位。
- 🔴3 背压：**严格串行**——上一块 `writable.write` 完成后再请求下一块，在途块≤1，杜绝内存堆积；小文件（< `STREAM_DISK_MIN`）自动走内存模式。
- 🔴2 断点：`showSaveFilePicker` 选中初始文件后，记录写到的偏移；中断/取消保留 `.part` 临时目标，下次「另存为」同文件可续写（带偏移/哈希校验）。
- 🔴1 原子性：**受限说明**——FS Access API 无法对用户选定路径做可靠原子 rename；实现为「写入目标 `.part` → 完成后完整关闭」；取消/失败 `writable.abort()` + 关闭句柄，资源不泄漏（残余原子性风险记 ⭐ 后续，若无满意方案在 UI 标注「可能不完整」）。

**流程**：能力探测 → `showSaveFilePicker`（须用户主动点击触发，安全约束）→ `createWritable()` → 串行 `fetchRange`（复用下载侧块校验/ETag）→ `writable.write(chunk)` → `close()`；进度 `{received,total,percent,speed}`；`AbortController` 取消。
