## 1. Context 与目标

P5-0/1 已交付 /artifacts 读取与版本链。当前前端产物面板仅「下载」。在线预览提升产物审阅效率。

**目标**：
- 图片/文本/代码/Markdown/PDF 产物面板展示「预览」，弹层内嵌渲染。
- **安全**：类型双重校验 + 魔数检测（🔴1）、Markdown 禁外部资源/伪协议/加固链接（🔴2）、SVG 安全边界（🔴4）。
- **稳定**：AbortController 可取消、单例预览、行数+大小双阈值、卸载兜底（🔴3）。
- **鉴权**：复用 `artifactBlob`（`Authorization` 头）→ objectURL；无 token 落 URL、无无鉴权直链。
- 兼容锚点：后端零改动；预览纯前端，默认仅新增按钮，不影响列表/下载/版本。

## 4. 关键设计

### 4.0 前端文件清单
- 新增 `client/src/lib/preview.ts`：`previewKind(rel, mime)`（双重校验+魔数）/ `readTextPreview(blob, limit)`（编码检测+行数截断）/ `markdownToReact(text)` / 常量（大小/行数阈值）。
- 新增 `client/src/components/ArtifactPreview.tsx`：预览 modal（AbortController + 单例 + 卸载兜底 + 错误分层）。
- 改 `client/src/pages/TaskDetailPage.tsx`：产物行加「预览」按钮（可预览才显示）；`openPreview(key)` → 渲染单例 `<ArtifactPreview>`。

### 4.1 类型判定：扩展名 + MIME 双重校验 + 魔数（🔴1）
- `previewKind` 返回 `{kind, ok}`；**扩展名与 Blob.type 任一不匹配 → 降级「仅下载」**，不进入预览。
- **魔数校验**（图片类）：读文件头前 8 字节比对——
  - PNG `\x89PNG`；JPEG `\xFF\xD8\xFF`；GIF `GIF8`；WEBP `RIFF....WEBP`；PDF `%PDF`；SVG 以 `<svg`/`<?xml` 开头（文本化校验）。
  - 魔数不符 → 拒绝预览（伪装 `.png`/`.pdf` 的 HTML/EXE 被拦）。
- **文本类编码检测**：先读前 4KB 特征字节（BOM：UTF-8 `EF BB BF`、UTF-16 `FF FE/FE FF`；否则按含非法 UTF-8 序列判定 GBK）。可解析→按检测编码 `TextDecoder` 解码；无法判定/含 NUL 大量→`previewKind` 返回 `unsupported`，提示「类型不支持预览」，禁止强制 UTF-8 读取。
- 判定表（扩展名 + MIME + 魔数 三重）：
  | 类型 | 扩展名 | Blob.type 前缀 | 魔数 |
  |---|---|---|---|
  | png | .png | image/png | ✓ |
  | jpeg | .jpg/.jpeg | image/jpeg | ✓ |
  | gif | .gif | image/gif | ✓ |
  | webp | .webp | image/webp | ✓ |
  | svg | .svg | image/svg+xml | 文本 `<svg`/`<?xml` |
  | pdf | .pdf | application/pdf | `%PDF` |
  | markdown | .md | text/markdown | 文本 |
  | text | txt/json/py/js/ts/sql/csv/log/yaml/yml | text/* | 文本 |
  | 其他 | —   | — | 不预览 |

### 4.2 Markdown 渲染安全（🔴2）
- **默认禁用外部图片**：`![alt](url)` 一律渲染为纯文本 `![alt](url)`（不生成 `<img>`，**不请求任何第三方资源**，杜绝跟踪像素/IP 泄露）。✅
- 链接协议严格白名单 `http/https`；`data:`/`ftp:`/`javascript:` 及一切变体（含 `java\nscript:`、大小写混合）→ 纯文本化，不生成可点击链接。
- 外部链接强制 `target="_blank" rel="noopener noreferrer"`，悬停 `title` 显示完整 URL，标注「外部站点」（🔴tabnabbing 加固）。
- 一律输出 **React 元素**；文本 `escapeHtml` 转义；**禁止 `dangerouslySetInnerHTML`**。
- 支持子集：标题/无序有序列表/`**粗体**`/行内码/代码块/表格/分隔线；其余回退纯文本。
- SVG 属静态图片，`<img>` 加载不执行内联 script；**不自动加载外部资源**（objectURL 隔离 + 不做可交互）。

### 4.3 内存与资源边界（🔴3 + ⭐3/4）
- **AbortController**：`ArtifactPreview` 每次打开创建 `AbortController`；关闭/切换/卸载先 `abort()` 终止拉取，再 `URL.revokeObjectURL`。
- **单例预览**：全局同时至多 1 个；打开新预览自动关闭旧的并释放。
- **行数阈值** `PREVIEW_MAX_LINES=2000`：超限截断渲染 + 提示「文件过大，仅显示前 2000 行」，防 DOM 爆炸。
- **大小阈值**：文本 `PREVIEW_TEXT_LIMIT=512KB`；二进制(图/PDF) `PREVIEW_BINARY_LIMIT=8MB`。超限提示「过大请下载」，不读取/不生成 objectURL。
- **解码/编码**：编码检测失败 → `unsupported`，不强制读取。
- **卸载兜底**：`useEffect` cleanup 统一 abort + revoke + 清定时器/监听。
- **PDF 兼容降级**（⭐3）：`previewKind('pdf')` 时特性检测（`navigator` 无可靠标志），用 `<iframe>` 尝试 + onerror 提示「浏览器无法内嵌 PDF，请下载」；不支持环境隐藏预览按钮，仅下载。PDF objectURL 加载失败态兜底。
- **加载进度**（⭐4）：modal 顶部加载中骨架 + 「拉取中…」；`AbortController` 超时（`PREVIEW_FETCH_TIMEOUT=15s`）提示「加载超时」。
- **编码自动检测**（⭐2）：见 4.1 文本编码检测，GBK/GB2312 自动转码。

### 4.4 异常状态分层（⭐1）
- 拉取 401 → 触发 `onAuthLost`（登出）。
- `artifactBlob` 抛 `ApiError(404)` → 「文件不存在」；非 200（后端 404 越权/缺失）→ 「无权限或文件不存在」；网络/超时 → 「网络异常，请重试」；编码/解码失败 → 「编码不支持或文件损坏」；超限 → 「文件过大，请下载」。
- 各错误态独立文案 + 「下载」兜底入口。

### 4.5 鉴权与审计
- 数据经 `api.artifactBlob`（`Authorization`）；objectURL 为 `blob:`，无 token 落 URL、无直链。
- ⭐5 审计：后端 `artifact_get` 不变；如需区分，后续可在前端触发时带 `?preview=1` 或由后端 activity 标记（本迭代：不改协议，留待后续；前端图上不新增请求）。

### 4.6 无障碍（⭐6）
- 打开自动聚焦内容区；`role="dialog"` `aria-modal`；Esc 关闭 + 点击遮罩关闭；关闭后焦点回触发按钮；`aria-label` 标注文档名。

## 6. 测试要点

### 必须覆盖（审查核心）
1. **类型欺骗**：改扩展名 HTML→`.png` / EXE→`.pdf`，魔数不符 → 不预览，仅下载。
2. **XSS**：Markdown 含 `<script>`、`javascript:`/`data:` 变体、外部图片 `![x](url)` → 全部转义/纯文本化，不执行不请求；`target=_blank rel=noopener noreferrer` 断言。
3. **内存释放**：多次打开/关闭/切换 → `revokeObjectURL` + `abort` 调用断言，无残留。
4. **边界**：恰达 `PREVIEW_TEXT_LIMIT` 正常；超限 → 提示不读取；`PREVIEW_MAX_LINES` 截断。
5. **异常**：401→登出；404→文件不存在；网络→重试提示（mock 断言文案）。
6. **并发**：快速连续打开 → 仅保留最新，旧资源释放。
7. **Markdown 渲染**：标题/列表/代码块/表格/粗体/行内码正确；特殊字符转义。
8. **回归**：不预览时列表/下载与 P5-1 一致；后端 167 零漂移；前端 build。

### 集成验证
- Agent 产出 md/png/pdf → 前端预览链路（图片/文本/Markdown/PDF 各一）。
- 二进制仅下载、无预览入口。

## 7. 验收标准
1. 图片/文本/代码/JSON/Markdown/PDF 可预览；二进制仅下载；
2. 类型欺骗（改扩展名/伪 MIME/假魔数）被拦，不进入预览；
3. Markdown 无 XSS（外部图不加载、伪协议剥除、链接加固）；
4. 单例预览 + abort + revoke，多次开合无内存增长；
5. 文本行数/大小阈值截断，DOM 不爆炸；
6. 鉴权正确：401 触发登出、越权 404 提示、无 token 进 URL；
7. 后端 167 零漂移、前端 build 通过。

## 8. 风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 类型欺骗绕过 | 脚本注入/隐私泄露 | 扩展名+MIME+魔数 三重校验；不符降级下载 |
| Markdown 外部资源跟踪 | IP 泄露 | 默认禁外部图片，不请求第三方 |
| 伪协议注入 | XSS | 协议白名单 + 转义 + 禁 dangerouslySetInnerHTML |
| 大文件 DOM 爆炸 | 卡顿崩溃 | 行数+大小双阈值，截断 |
| 多预览内存叠加 | 标签页崩溃 | 单例预览 + abort/revoke |
| PDF 兼容 | 空白 | 特性检测 + onerror 降级下载 |

> 回滚：移除预览组件即完全回退；后端零改动。
