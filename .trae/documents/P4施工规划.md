# P4 施工规划：集群化部署 + 告警外部通知 + RBAC 协作 + 成本统计（最高强度审查修订版）

> 状态：**最高强度深度审查后修订**。采纳全部 🔴/⭐ 项。未修正会出现的生产级问题（越权、重复执行、产物失联、告警风暴、聚合超时）已在此版闭环。

## Context（为什么做）

P3 已交付**多 worker 水平扩展 + 监控告警 + 多用户 owner 隔离 + 前端任务路由**。用户选定 P4 四块：**跨机器集群化部署、告警外部通知、RBAC 角色与协作分享、成本统计与账单**。前端打磨与任务优先级记为可选叠加。

**兼容锚点（审查⭐）**：一切增量功能**默认全关闭、开关独立可控**；`AUTH_ENABLED`+`USE_QUEUE` 双关时行为与 P3/P2 零漂移（CI 回归锚）。

## 最高强度审查修订落地（全部 🔴/⭐）

### 🔴 全局架构
1. **跨机器时钟同步强制前提**：集群部署所有节点必须 NTP 同步、偏差 ≤1s；服务启动做系统时间校验（偏差超阈值拒绝启动 + 告警）；所有时间判断（lease/心跳/TTL）统一服务端时间，不采客户端/实例本地时间。
2. **增量功能默认全关、独立开关**：
   - `ENABLE_ADMIN=false`：`/admin/*` 一律 404，实例注册仅后台运行不暴露端点；
   - `NOTIFY_RULES={}`：零外部通知，监控采集不变；
   - RBAC：`AUTH_ENABLED=false` 时 `can_view/can_edit` 恒 True，权限校验完整短路；
   - 优先级：`ARQ_PRIORITY_ENABLED=false`：单队列，与 P3 一致。
3. **全局 trace_id**：入队/执行/事件/审计/通知/成本全链路携带唯一 trace_id，跨模块可追溯。
4. **管理操作全审计**：admin、分享变更、成本导出、配置变更，全写 AuditLog（user_id、操作、来源 IP）。

### 🔴 P4-1
1. **NTP + 启动时钟校验 + 统一服务端时间**（同全局 1）。
2. **产物跨机器不可访问红线**：文档大字号标注「P4 仅保证任务调度/执行分布式，产物文件在执行节点本地，跨节点不可访问」；产物路径落 DB TaskNode；前端访问不到时明确提示；S3/对象存储列为 **P5 核心需求**。
3. **实例 ID 全局唯一**：`WORKER_ID` 强制 `hostname-pid-randhex`，注册时校验唯一性（重复则拒绝）。
4. **死扫描锁全局正确性确认**：确认为 **Redis 全局分布式锁**（SET NX EX，已由 P3 实现），锁粒度为集群全局单例，锁 TTL 与扫描周期匹配；文档写明跨机器依然唯一。
- ⭐ 实例注册脱敏（只存 host 名，不存内网 IP/路径）；集群视图健康分级 online/degraded/offline；实例退出主动注销。

### 🔴 P4-2
1. **通知异步化**：监控 tick 只生产事件入队，独立消费任务异步发送；**失败不回抛、不阻塞监控主循环**。
2. **告警风暴双重防护**：触发与恢复**各自独立冷却期**；加单位时间最大通知数上限，超限自动静默 + 写「告警风暴」审计。
3. **通知内容白名单（安全红线）**：仅允许 指标名/阈值/触发时间/实例id/状态；**禁止**任务内容、用户隐私、内部路径、代码片段、配置、token/密码。
- ⭐ 分级路由（warning→webhook，critical→邮件）；按时间段静默；失败指数退避 3 次后记审计，当日内不再重试。

### 🔴 P4-3
1. **全操作权限校验，无散点**：枚举全部读/写操作（list/get/nodes/advance/decision/删除/分享管理/节点回退/强制终止/产物删除），读走 `can_view`、写走 `can_edit`，无例外。
2. **二次分享禁止**：仅 owner 与 admin 可管理分享（添加/删除）；editor/viewer 无分享管理权，阻断权限扩散。
3. **越权统一 404**：无权限与资源不存在一律 404，杜绝任务 ID 枚举。
4. **降级迁移破坏性警示**：RBAC 迁移 downgrade 会删除 role 与 task_shares（数据永久丢失），**回滚优先用配置关闭权限体系**而非降级迁移；确需降级前必须备份。
- ⭐ 不支持任务所有权转让（需 admin 后台）；分享支持有效期到期自动收回；**WS 权限实时生效**（分享撤销即停止推送，不等重连）。

### 🔴 P4-4
1. **聚合性能**：`audit_logs` 增 `(created_at, action)` 联合索引；P4 仅支持近 30 天聚合，更长周期留 P5 离线。
2. **多模型正确计费**：聚合粒度到 **task + model** 分别匹配单价再汇总；模型不在定价表单价记 0 + 记录警告。
3. **优先级饥饿**：严格抢占模式（文档明示饥饿风险）+ **最低保障**：每处理 N 个高优任务强制处理 1 个低优任务防永久饥饿。
- ⭐ 单任务成本明细；CSV 导出 UTF-8 BOM 兼容 Excel；成本阈值预警接入通知。

### 风险/回滚增强（🔴）
- 跨机器部署前置检查清单：NTP、网络连通、Redis/DB 可访问、时钟偏差校验。
- RBAC 降级为破坏性，执行前备份；优先配置回滚。
- 优先级关闭后：已入队任务保留原队列执行完，新任务走默认队列。

## 分阶段实施（依赖：集群 → 通知 → RBAC → 成本）

### P4-1 跨机器集群化部署
- **目标**：恒跨机器可部署、可观测；实例注册/心跳/集群视图 + 一键拓扑。
- **复用**（P3 已具备，跨机器天然生效）：Redis 全局分布式锁 + lease 续期 + 死信；Pub/Sub 事件 + seq 去重；多 API owner 过滤；WORKER_ID 自动生成。
- **改动**：
  - 新增 `app/observability/instance_reg.py`：实例注册表 `zw:instances:{id}`（kind/host/pid/started_at/ttl=心跳×3），启动注册、周期续期、退出注销；启动时钟校验；注册 ID 唯一性校验。
  - `app/observability/metrics.py`：并入实例统计 + 集群健康分级。
  - 新增 `app/api/admin.py` `/admin/cluster`（`ENABLE_ADMIN` 控制，AUTH admin 可访问）。
  - `config.py`：`INSTANCE_HEARTBEAT_TTL`、`ENABLE_ADMIN`、`MAX_CLOCK_SKEW`。
  - `docker-compose.workplace.yml`、`Makefile`、README（含 NTP/产物边界）。
- **库变更**：无（全走 Redis TTL）。
- **验收**：双 worker `/admin/cluster` 显示 2 worker+1 api、健康分级正确、kill 后 TTL 剔除；时钟偏差注入拒绝启动；`ENABLE_ADMIN` 关→404；双 worker 任务全完成、扫描锁仅一命中、事件无重复。
- **测试**：注册/续期/注销、扫描锁单例、心跳 TTL 剔除、时钟校验、admin 鉴权、产物跨节点不可访问状态。

### P4-2 告警外部通知
- **复用**：`run_monitor_tick` 事件、`ALERT_COOLDOWN`。
- **改动**：
  - 新增 `app/observability/notify.py`（Notifier 抽象 + async 投递队列）与 `notifiers/{webhook,smtp,wecom}.py`。
  - `alerts.py`：事件带 level/instance；触发+恢复各自冷却；每分钟上限 → 风暴审计。
  - `appstate.py`：monitor 生产 → 独立异步消费；失败捕获、不回抛、3 次指数退避。
  - `config.py`：`NOTIFY_RULES`、`SMTP_*`、`WEBHOOK_URLS`、`WECOM_WEBHOOK_*`、`NOTIFY_MAX_PER_MIN`。
- **安全**：payload 白名单（指标/阈值/时间/实例/状态）；禁业务与隐私数据；规则默认空。
- **验收**：stub httpbin 收到 trigger/resolve；冷却去重 + 恢复冷却；风暴抑制；渠道失败不阻塞监控 + notify_failed 审计；无配置时与 P3 一致。
- **测试**：异步不阻塞、冷却/恢复/风暴、内容白名单、失败退避。

### P4-3 RBAC 角色与协作分享
- **改动**：
  - `models.py`：`User.role(admin|user)`、`TaskShare`；迁移 `<rev>_p4_rbac_task_share.py`（含 system 账号 role=admin；标破坏性 by preserve data）。
  - 新增 `auth/permissions.py`：`can_view/can_edit/can_manage_share` 唯一判定；AUTH off 全短路。
  - `repos.py`：share CRUD + 权限查询 + 全操作 owner/share/admin 过滤。
  - `main.py`/`ws.py`：所有权判定替换为权限函数；分享管理路由（仅 owner/admin）；越权统一 404；WS 实时推送过滤按 shares∪owner∪admin。
- **库变更**：users.role + task_shares；`downgrade` 破坏性（文档警示、备份提示）。
- **验收**：admin 全见全改；viewer 只读/editor 读写；仅 owner/admin 管分享（editor 加分享 404/403→统一 404）；越权统一 404；共享用户 WS 收到事件、撤销即停；AUTH off 零漂移。
- **测试**：全操作越权、二次分享禁止、404 统一、admin 全局、WS 精准推送+实时撤销、AUTH 兼容。

### P4-4 成本统计与账单（+ 可选优先级）
- **真相源**：`audit_logs.detail.result.usage{prompt_tokens,completion_tokens}`（P1 起全量落库）。
- **改动**：
  - 迁移：`audit_logs` 增 `(created_at, action)` 索引（可选 priority 时 tasks.priority index）。
  - `repos.py`：`usage_summary(by task+model, 近30天)`；缺失 usage 记 0。
  - `config.py`：`MODEL_PRICING`、`ARQ_PRIORITY_ENABLED`、`ARQ_QUEUE_HI`、`MIN_FAIR_HIGH_BATCH`。
  - 新增 `api/billing.py` `/billing/summary`、`/billing/export.csv`（UTF-8 BOM，授权隔离，非 admin 仅看自己）。
  - 优先级：分级队列 `zeffy_hi/zeffy_lo` + 最低保障（高优 N 后强制处理 1 低优）；`ARQ_PRIORITY_ENABLED=false` 单队列。
- **验收**：多模型聚合金额正确；缺 usage 容错；近 30 天限界；非 admin 隔离；CSV 中文不乱码；优先级先高优且低优不被永久饿死；优先级关闭回 P3 行为。
- **测试**：聚合 SQL 断言、多模型计价、权限隔离、CSV BOM、优先级顺序 + 公平轮转。
